The Physics of Abrikosov Vortex Flow

In Type-II superconductors, when the applied magnetic field exceeds the lower critical field Hc1, the magnetic field is no longer completely expelled (which is the Meissner effect). Instead, it penetrates the material in the form of quantized tubes of magnetic flux called Abrikosov Vortices, named after Alexei Abrikosov.

This dashboard solves the 2D Time-Dependent Ginzburg-Landau (TDGL) equation in real-time. We model the superconducting state using a complex order parameter ψ(x,y), where the local condensate density is |ψ|2.

  • Phase Winding: Around each vortex core, the phase of the order parameter wraps by exactly 2π. The vortex core is a normal-state region where ψ = 0, allowing the magnetic field to pass through.
  • Lorentz Force & Depinning: When a transport current Jx is applied, it exerts a transverse Lorentz force FL = J × B, pushing the vortices vertically. If the vortices are pinned by material defects (painted in red), they remain static and the voltage remains zero. When the current exceeds the critical pinning threshold, the vortices depin and flow, generating an electric field (flux-flow resistance) that you can see on the oscilloscope and hear as a deep humming buzz.
  • Lattice Formulation: To ensure strict numerical gauge invariance under high magnetic fields, we implement a lattice gauge-invariant covariant Laplacian using link variables Uy = exp(-i H x Δy).
