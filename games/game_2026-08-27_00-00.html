How it Works: The Phase-Field Method

Modeling crystal growth like snowflakes is historically difficult because tracking a sharp, moving boundary is computationally nightmarish. The Phase-Field Model solves this by introducing a continuous variable, the phase field φ, which goes from 0.0 (liquid) to 1.0 (solid). The interface is represented as a narrow transition zone where φ changes smoothly.

This simulation solves the Kobayashi Phase-Field Equations (R. Kobayashi, 1993) on a 150×150 grid at up to 900 steps per second. The state updates are governed by two coupled partial differential equations (PDEs):

  • Phase Evolution (φ): ∂φ/∂t = ∇ · (ε² ∇φ) + ∂_x(εε' ∂_yφ) - ∂_y(εε' ∂_xφ) + φ(1-φ)(φ - 0.5 + m(T)) + noise
  • Thermal Diffusion (T): ∂T/∂t = D ∇²T + K ∂φ/∂t

Here, m(T) = (α/π) arctan(γ(1 - T)) represents the thermodynamic driving force: supercooled liquid (where T < 1) drives φ to expand, releasing latent heat K ∂φ/∂t into the local thermal field. Anisotropy is introduced in the interface thickness parameter ε = ε_bar (1 + δ cos(j(θ - θ0))), which biases growth along the preferred crystal axes (e.g. 6-fold for hexagonal snowflakes, 4-fold for cubic structures), giving rise to the beautifully symmetrical branches.
